TCG Quest V3 Unofficial Condition Assistant

Replace app.py and index.html in your repository root. Do not upload the ZIP itself.

The assistant uses computer vision for centering and photo-quality warnings, and user-supplied corner, edge, surface condition ratings for an illustrative 1–10 range. It is not a trained AI model, not a validated PSA prediction, and not affiliated with PSA. Both photos and manually confirmed borders are required. No grade is returned if any required information is missing.
